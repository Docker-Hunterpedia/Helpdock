Admin/Ticketing-FieldFilters (+ CustomFields, required to close)

  • Filter popover and view editor take custom fields: select and multi-select (is any of, is not set), checkbox (is), number and date (before, after, between), text (contains). M14-26 adds Mailbox (any of) and Written to (exact address).
  • Pinned field: one select field per brand shows as a neutral chip on the row's meta line and in the ticket header (no new hue). The guide's Severity recipe uses it (D-21).
  • Field editor: four new types (long text, link, email, person) marked new; “Required to close” beside “Required when created”.
  • Closing with an empty required-to-close field opens this dialog instead (Close button and e); bulk previews list it per ticket. API-key closes are refused too (D-30); rules close and note the gap.
  • New types render: long text collapsed with Show all; link opens in a new tab and is never fetched; email in bdi dir=ltr; person with avatar and public name.
