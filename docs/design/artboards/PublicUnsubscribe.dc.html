Public/Unsubscribe

  • A public route in the admin bundle (like the CSAT page, ADR 0010), in the token's language. A mail client's one-click POST unsubscribes at once; a person's click opens this confirmation, so link scanners unsubscribe nobody.
  • Confirm → Done, which says what still reaches them. An expired or invalid token gets the third state; it never says whether the address exists.
  • Targets 44 px; works at 320 px wide.
