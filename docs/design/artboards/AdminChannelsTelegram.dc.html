How updates arrive
In production Telegram posts each update to Helpdock’s webhook and signs it with a secret token; requests without it are refused. Development installs poll with long polling instead, so no webhook is set and the Webhook column reads “Polling”.
Health
Healthy: the webhook is set and the last delivery or send worked.Behind: Telegram reports pending updates that have not arrived.Failing: Telegram’s last delivery failed, or the token was revoked.Waiting: saved, no update received yet.
