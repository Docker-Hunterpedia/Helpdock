Widget/PreChat-Verify

  • The built-in proof-of-work check (pow, M18-10) in the widget's pre-chat form, in the place the Turnstile box takes today (Widget/States). No puzzle, nothing to click.
  • The solver starts when the form opens, in a lazy chunk, so it is usually done before the visitor finishes typing. The strip shows Checking → Verified; Start chat stays disabled until it is verified.
  • Failure (expired challenge, solver error, network): the strip turns to the danger border with “Try again”, which fetches a fresh challenge. The message never blames the visitor.
  • Live region: checking is role=status polite; failure is role=alert. The spinner respects reduced motion (static icon).
  • Caption “Built-in” replaces the provider name; nothing loads from a third party and the CSP is unchanged.
  • Arabic: mirrored; the email field stays dir=ltr.
