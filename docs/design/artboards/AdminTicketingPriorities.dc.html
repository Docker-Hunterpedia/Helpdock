Admin/Ticketing-Priorities

  • M1-02, issue #453. Settings › Inbox › Priorities, after Statuses in the sidebar and the command palette. The old /settings/inbox/priorities and /admin/ticketing/priorities addresses open this page instead of redirecting to Departments.
  • Fixed set. Always four rows in the order Low, Medium, High, Urgent. No add, delete or reorder, and no colour picker: the pill tone and the urgent solid fill stay as DESIGN §6.2. API values, rules, SLA targets, imports and webhooks keep low | medium | high | urgent.
  • Two names per priority. English and Arabic, like Statuses. Staff see the name in their own interface language. An empty field means the default name, shown as the placeholder. Under a renamed pill a muted line keeps the default in view.
  • Rules. Trimmed; 1 to 24 characters; no line breaks. Within one language two priorities cannot end up with the same name, compared without case and against the defaults of the rows left empty. The error sits under the field that was edited last and Save moves focus to the first invalid field.
  • Saving. One form: Save and Discard stay disabled until something changes. Save writes all four rows at once, shows the toast and updates every open screen without a reload. The reset button on a row clears both of its fields (still needs Save); it is disabled when the row has no override.
  • Failure. A refused or failed save keeps what was typed and shows the error banner above the table. A field error returned by the server lands under its field.
  • Who. Needs ticketing:manage, the same as Statuses. Everyone who can read tickets receives the names; other roles do not see the page in the sidebar or palette.
  • Scope. Staff surfaces only: ticket list, header, priority menus, bulk edit, templates, rules, SLA policies, routing trail, activity, filters and reports. Customers never see a priority. Each brand has its own names.
  • Accessibility. A real table with row headers. Each input is named for its row and language ("High in Arabic"); Arabic inputs are dir=rtl lang=ar and English ones dir=ltr lang=en in both interface directions. Reset buttons carry the row name. The pill is not the only place the name is given.
  • Narrow screens. Under 720 px each row stacks: pill, then the English field, then the Arabic field with visible labels, reset at the row end.
