Password field

Used wherever a password is chosen: accept invitation, password reset, Account › Security › Change password, and the wizard's admin step. The show/hide IconButton sits inside the Input at its inline end. Panels 3 and 4 are what the api refuses on submit, shown as the field's error.

1 · Hidden (default)
At least 12 characters. Strong.
2 · Shown
At least 12 characters. Strong. Hidden again when the form is sent.
3 · Too short
Use at least 12 characters. 7 so far.
4 · Found in a breach list
This password appears in lists of leaked passwords, so attackers try it first. Choose another one.
Checked on this server against a bundled list. The password is never sent anywhere else.
5 · بالعربية، معكوس
تظهر كلمة المرور هذه في قوائم كلمات مرور مسرّبة، لذا يجرّبها المهاجمون أولاً. اختر كلمة أخرى.
Toggle. A 32 px ghost IconButton with aria-pressed, named "Show password" / "Hide password". Shown text is mono so similar characters can be told apart. The field returns to hidden when the form is sent or the page is left.
Strength. The existing PasswordStrengthBar. Below 12 characters or on a breach-list match it drops to one danger segment.
Errors. Shown after the api answers, not while typing; the hint becomes the error with role="alert" and the Input gets aria-invalid.
