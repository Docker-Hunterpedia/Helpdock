Rules. Admin base is 14 px. Widget and help center base is 16 px. Line-height is always a multiple of 4.
Arabic. Same sizes and weights. No letter-spacing, no uppercase transforms, no italics. Numbers and ticket ids stay Latin and LTR inside RTL text.
Fallbacks. Self-host the woff2 files in packages/ui; system stack is ui-sans-serif, system-ui. Never load fonts from a third party in the widget.
