Email/SecurityChange (M18 events)

  • Amends the securityChange email: same layout as the other system emails (Email/StaffNotification), in the account's app language.
  • New events: passkey added, passkey removed, sign-in method connected, sign-in method disconnected (same shape as connected). Password reset gains the passkey count and the review advice.
  • Each names the thing that changed, when (in the person's time zone), where from when known (browser and a truncated IP), and one action.
  • The “if this wasn't you” line uses the danger text colour. Passkey and account names in bdi; email addresses dir=ltr.
  • Security emails ignore notification preferences and digests (M14-10/11).
