Helpdock 1.0.0. Every milestone of the 1.0 plan is in: ticketing with SLAs, rules and macros; email, Telegram, WhatsApp, Messenger and Instagram, the chat widget and the web form; a bilingual help center; grounded AI with agent assist and auto-reply; the REST API, webhooks and reports; staff sign-in over SAML and OpenID Connect; and importers from Zendesk, Freshdesk and Zoho Desk with a manual CSV mapper. Since 0.7, the ticket's contact card lists the contact's previous tickets, and auto-reply hands off (`NO_ANSWER`) when its sources do not answer the exact question. The bilingual AI evaluation passed every DOMAIN-RULES §9 threshold with `glm-4.6` answering and `glm-5.1` judging (run 39322685646: answerable 97.5 % en, 94.6 % ar; unanswerable handed off 100 %; one provider pair). The major version marks the release, not an incompatible change: an install on 0.7 upgrades as for any release, with a new image tag and a restart, and its migrations run when the api starts. SSO and the importers were verified against stand-in identity providers and vendor servers built from the vendors' published API documentation, not against live Okta or Entra ID tenants or live Zendesk, Freshdesk or Zoho Desk accounts.
