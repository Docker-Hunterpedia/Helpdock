M14 amendments: Admin/RuleBuilder, Admin/Developers-Webhooks, Admin/Reports

  • RuleBuilder (M14-26): conditions Mailbox (is, is not, any of) and Written to (is, contains), on the arrival facts; actions Set reply address (only mailboxes the ticket's department may use) and Mark as spam. Tickets from before 1.1 never match them.
  • Webhooks (M14-28): the event picker grouped by Tickets, Messages, Contacts and accounts, with the new events tagged; an opt-in for note bodies in message.created.
  • Reports (M14-29): Volume by tag (top 20, CSV) and Backlog by status with the unassigned share, under the reader's department scope, in the report palette.
  • “new” is a neutral Tag shown only in the release that adds them.
