Require single sign-on

When on, local sign-in methods stop working for everyone except the break-glass admins below.

Break-glass admins sign in with their password and an authenticator code or a passkey. Recovery codes, trusted browsers and passwordless passkey sign-in do not count.

Ola Saeed can't be a break-glass admin yet: add a password and an authenticator app or a passkey first.

Admin/Settings-SSO (M18 amendments)

  • Admin/Settings-SSO-Connection: a “Start from” select above the protocol fields with Custom OpenID Connect, Google Workspace (OIDC) and Microsoft Entra ID (OIDC). Choosing a preset fills the issuer or discovery template, claim names and the domain hint, and shows an info Banner linking to its guide section. Editing a field afterwards does not reset the preset. Saved connections do not store which preset was used.
  • Presets exist only for OIDC; GitHub is not OIDC and stays a sign-in button.
  • Admin/Settings-SSO: the break-glass copy names “an authenticator code or a passkey” (D-50, ADR 0053). The picker refuses a person without a password and (TOTP or passkey), with the warning shown.
  • No other change to either screen.
