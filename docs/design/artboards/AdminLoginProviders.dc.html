Admin/Login-Providers

  • Amends Admin/Login: up to three provider buttons in one row, in this order: Google, Microsoft, GitHub. Only configured providers are drawn; the grid keeps equal columns for 1, 2 or 3.
  • Marks are monochrome inline SVGs from provider-marks.tsx (DESIGN §5 amendment adds the four-square Microsoft mark). No brand colours.
  • Buttons never create accounts. An identity that is not yet bound, and that the provider is not authoritative for, lands on the oauth-link-required screen (en, ar). GitHub always lands there on first use.
  • The callback error screens share one layout: logo, title, one paragraph, optional steps, one primary “Back to sign in”. They never say whether an account with that email exists.
  • Domain and tenant refusals are separate codes (oauth-domain-not-allowed, oauth-tenant-mismatch) with their own copy; the conflict screen from 1.0.1 (oauth-identity-conflict) is unchanged.
  • Arabic: mirrored; provider names stay Latin.
