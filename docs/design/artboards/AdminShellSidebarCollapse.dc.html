Admin/Shell-SidebarCollapse

Owner request (1.0.2): the admin sidebar can be collapsed to a 56 px icon rail and expanded again.

  • Expanded (220 px, unchanged): a 32 px "Collapse sidebar" row above the user card, Lucide PanelLeftClose (mirrored in RTL) and the shortcut hint ⌘\ / Ctrl+\.
  • Collapsed rail (56 px): brand mark, 36 px icon buttons for primary nav, a single Views icon (Lucide Layers) that opens the views list as a popover, the Admin items as icons, an "Expand sidebar" button (PanelLeftOpen) and the user avatar. Counts become a 16 px badge on the icon; the full count stays in the accessible name ("Tickets · 38").
  • Every rail icon has an aria-label and shows a Tooltip on hover and keyboard focus (bg.inverse, 12/16), placed at the inline end.
  • The toggle is a button with aria-expanded and aria-controls; focus stays on it after toggling. Shortcut ⌘\ / Ctrl+\ (joins the M14-01 registry; it is a modifier shortcut, so WCAG 2.1.4 does not apply).
  • The choice is remembered per browser (localStorage, wrapped in try/catch); default expanded at ≥ 1280 px, collapsed between 1024 and 1279 px; below 1024 px the sidebar is the existing drawer.
  • Width animates 160 ms; none under prefers-reduced-motion. Logical properties only; the rail sits at the inline start in Arabic.
