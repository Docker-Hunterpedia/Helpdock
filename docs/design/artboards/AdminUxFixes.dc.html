Admin/UX-Fixes-2026-11

  • Settings in the sidebar. No second column. Settings expands in the main sidebar with a chevron: groups, then each group's pages on a guide line. One group open at a time; the current page's group opens by itself and the current page is scrolled into view. Group rows only expand. Outside Settings, clicking Settings opens its first page.
  • Space. While in Settings, Views folds up without changing the person's saved choice, and returns on leaving. The sidebar's nav area scrolls by itself.
  • Collapsed sidebar. The gear opens a flyout with the same groups and pages. Narrow screens. Same tree inside the sidebar drawer; choosing a page closes the drawer. The page takes the full width, capped at 1040 px; a new page opens at the top; a #hash scrolls to its section with a 16 px margin.
  • Statuses. Name and translated name stack in one column in the reader's language first. Type gets its own column so chips align. The always-blank Tickets column goes; the editor keeps the count. Names never wrap or centre (Views too).
  • Widget preview. Sits beside Appearance from 1200 px and stays in view while editing. It draws the selected Mode. Light or Dark in the form drives the preview and hides its theme toggle; Auto keeps the toggle.
  • Not found. An unknown signed-in address gets this page inside the shell. Old URLs still redirect first.
  • Moved. Data retention leaves Danger zone for Brand › Data retention. Your details (email, language) leave Security for Profile; Name appears once.
  • Forms. Labels sit above fields everywhere. Save and Discard stay disabled until something changes. Settings content is capped at 1040 px.
