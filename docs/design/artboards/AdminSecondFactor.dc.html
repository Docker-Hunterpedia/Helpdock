Admin/SecondFactor

  • Amends Admin/TOTP. Shown after a password, sign-in link, Google/Microsoft/GitHub, or an SSO connection that does not vouch for IdP MFA.
  • Order: “Use your passkey” first (primary) when the account has at least one passkey, then the authenticator code (when TOTP is on), then the recovery-code link. An account with only TOTP sees today's screen unchanged.
  • “Use your passkey” runs a non-discoverable ceremony with the account's credentials in allowCredentials; user presence is enough, so a security key without a PIN works.
  • One attempt budget across passkey, code and recovery code: three failures, then the 15-minute lock. The error banner names attempts left, as today.
  • A cancelled browser prompt is not a failure and leaves the counter as it was.
  • “Trust this browser” applies to whichever factor succeeds.
  • Arabic: mirrored; the code input stays dir=ltr and centred.
