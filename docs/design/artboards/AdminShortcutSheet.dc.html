Admin/ShortcutSheet

  • ? (also the Arabic ؟) or the palette's “Keyboard shortcuts” opens this dialog. Every row comes from the shortcut registry, so the sheet cannot drift from what the keys do.
  • Five groups in three columns: General, Go to, List, Ticket, Composer. Keys use the new Kbd component (DESIGN §6.2); sequences read “g then i”.
  • Letters match the physical key (event.code), so they work on an Arabic keyboard layout; the sheet shows the Latin letter.
  • Footer: the single-key shortcuts switch (stored on the account, default on, D-32). Off greys out every key without a modifier (WCAG 2.1.4).
  • While a g sequence waits (1.5 s) a small status chip at the bottom of the screen lists the next letters.
  • Focus starts on the dialog title; Esc closes and returns focus to where it was.
