Calling the API

curl https://api.helpdock.io/v1/tickets \
  -H "Authorization: Bearer hd_live_…" \
  -H "Idempotency-Key: 8c1e5f0a-order-10442" \
  -d '{"subject":"Order 10442 arrived damaged","contact":{"email":"mona.khalil@example.com"}}'
Send an Idempotency-Key on every create: a retry with the same key returns the first result instead of a second ticket. The full reference is the OpenAPI 3.1 document at /api/docs.

How keys work

A key is shown once, when it is created. Helpdock stores only its SHA-256 hash, so a lost key is revoked and replaced, never recovered.
Each key reaches this brand only, and only what its scopes allow. A request over the key's rate limit gets 429 with Retry-After.
Creating and revoking keys is recorded in the audit log.
