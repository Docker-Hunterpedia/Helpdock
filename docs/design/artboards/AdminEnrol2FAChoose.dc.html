Admin/Enrol2FA-Choose

  • Amends Admin/Enrol2FA. Shown on second-factor-enrolment-required (the old totp-enrolment-required stays an alias for one release).
  • Two radio cards, passkey first and marked Recommended (a Tag). Continue starts the chosen path.
  • Passkey path: the browser prompt (registration ceremony, residentKey: preferred), then “Name this passkey” with a suggested name from the platform (editable, 64 characters, truncated on a code-point boundary for Arabic), then the existing recovery-codes step (Step 2 of 2) unchanged.
  • Authenticator path: today's Admin/Enrol2FA step 1 (QR and key), then the same recovery-codes step.
  • If the browser cannot use passkeys, the passkey card is disabled with the reason as its description and the app card is preselected.
  • A cancelled prompt returns to the chooser with a neutral notice; nothing is saved.
  • Arabic: mirrored; app names stay Latin.
