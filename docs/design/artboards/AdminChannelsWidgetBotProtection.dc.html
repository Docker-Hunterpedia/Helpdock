  • Amends the access card in Admin/Channels-Widget. The provider select gains “Built-in (no third party)” first.

  • New brands that turn the check on start with Built-in (D-51); existing brands keep their provider.
  • Turnstile and hCaptcha keep today's fields; a one-line caption states the data trade-off.
  • The same choice drives the web form (one setting per brand).
